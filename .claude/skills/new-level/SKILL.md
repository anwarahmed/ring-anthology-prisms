# Building a level

**Read only:** the level's entry in `docs/CAMPAIGN.md`, `docs/ENGINE.md`, and
`levels/_template/level.js`. Don't read other levels or the engine source. If the
engine must change, change it, update `docs/ENGINE.md` in the same change, and say so.

Copy this checklist into your task list and tick each step.

```
- [ ] 1. Spec read (CAMPAIGN.md entry: era, players, echo, story, sacrifice, play, enemies, boss)
- [ ] 2. Canon verified: lore-check skill run; every (verify) in the entry cleared or the fact dropped
- [ ] 3. Archive cards written: canon only, kid-readable, each with a source
- [ ] 4. Content exists: characters, units, weapons, theme, music (new-content skill for anything missing)
- [ ] 5. Map designed: generated by script, arenas ≤ 30 tiles wide, markers placed
- [ ] 6. Script written: the EPIC beats below
- [ ] 7. npm test passes
- [ ] 8. Playtested: playtest skill, the bot finishes the level, screenshots reviewed
- [ ] 9. CAMPAIGN.md status set to done (only once there are no (verify) items left)
- [ ] 10. Legal checklist (docs/LEGAL.md) passes for everything added
```

## 1–3. Story

- Run the `lore-check` skill on the entry first. Fix the entry in CAMPAIGN.md (and the
  timeline in LORE.md) wherever Halopedia disagrees. Record the sources in the level
  file's header comment.
- **Cards:** 2–4 `before`, 1–3 `after`. Short sentences a 7-year-old can follow. Each
  card names its source. If CAMPAIGN.md lists an archive scene just before this level,
  it becomes this level's first `before` cards.
- **`say` lines:** only exact canon quotes (with `source`) or neutral narration of
  canon facts. When unsure, use an objective or an Archive card instead.
- Apply the kid-friendly rules in LORE.md: no blood, and deaths are told gently.

## 4. Content

Check the spec's enemies, players and vehicles against `src/content/`. Anything missing
→ the `new-content` skill. Reuse before adding: a generic role can often reuse an
existing unit with a new palette.

## 5. Map

Write a small Python or Node generator in `test-results/` (gitignored) that paints
rectangles, and paste its rows into `map`. Paint markers **last** so nothing
overwrites them. Shape for a ~6–10 minute level:

- An intro stretch to learn the era kit, then 2–4 arenas (lock between markers, ≤ 30
  tiles wide), with travel sections and light ambushes between them.
- Platforms at 2–3 heights in arenas, cover blocks, a hazard or two.
- Use the era kit: a gap for the hard-light dash, high ledges for the Grappleshot, and
  so on.
- Echo levels: reuse the partner level's map, changing tiles and theme to show the
  other time.

## 6. Script: make it EPIC

Every level needs at least:

- **Opening objective,** and music at intensity 0.
- **Escalation:** each arena harder than the last (more units, then tougher ones).
  `intensity: 1` in combat and `intensity: 2` at the climax.
- **A checkpoint** after each arena.
- **A set piece:** a `hold` defense, a boss with a `boss` title card, or a hook (a
  bombardment, a collapse, a slow-motion moment).
- **An ending:** `{ end: { result: 'win' } }` or `'history'` for canon defeats, after a
  closing beat (slow motion, a flash, a letterbox, a narration line).
- Difficulty is handled by the engine; design for Normal.

## 7–9. Finish

- `npm test` must pass (the validator catches missing markers, unknown units, and
  missing sources).
- Run the `playtest` skill. The bot must reach the results screen. Look at the
  screenshots for overlapping HUD text, empty arenas, and players stuck or off screen.
- Set `- **Status:** done` in the CAMPAIGN.md entry. The validator refuses `done` while
  `(verify)` remains.
- Commit the level, plus any content or engine changes, together.
